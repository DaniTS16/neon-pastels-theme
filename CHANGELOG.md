# Neon Pastels — CHANGELOG

## 1.2.0 — Current Release

This release formalizes Neon Pastels as a Theme Garden–ready product.  
Major improvements include:

- Full brand lock enforcement across theme and documentation
- Introduction of a static Tumblr theme (`index.static.html`)
- Addition of a standalone preview page (`preview.static.html`)
- Inclusion of preview PNG placeholders for Theme Garden submission
- Updated Tumblr option names to conform to Tumblr’s no‑space key requirements
- Added CHANGELOG.md, BRANDING.md, and STATIC-THEME-NOTES.md
- Improved WCAG contrast tokens for both light and dark palettes
- Enhanced motion system with clearer reduced‑motion behavior

## 1.1.0

- Added Neon palette for dark mode
- Introduced Magazine layout with multi‑column support
- Added glow intensity controls for neon mode

## 1.0.0

- Initial public release of Neon Pastels
- Included Pastel, Peach, and Lilac palettes
- Added Single and Wide layouts
- Implemented brand‑governed motion system
